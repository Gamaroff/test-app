# Wireframe Examples

## Dynamic Brief-to-Outline Mapping

```yaml
Example: Dynamic Mobile Screen (Generated from a specific brief)

# The agent must NEVER use a hardcoded template. This outline must be 
# generated dynamically based on the exact user request.

Viewport: Mobile (Base 375px)
Screen: [Bespoke Name from Brief]

Header_Zone:
  - [Action Button Left / Back Label]
  - [Dynamic Title / Logo Text]
  - [Widget Area: e.g., Streak Widget: 7d]

Main_Scroll_Zone:
  - [Unique Component 1: e.g., Media Placeholder Box (with crossed diagonal lines)]
  - [Unique Component 2: e.g., Product Title and text description outlines]
  - [Unique Component 3: e.g., Custom data visualization charts using outline grids]

Bottom_Fixed_Zone:
  - [Navigation Capsule: e.g., Floating pill-shape containing text links like [Home], [Search], [Settings]]
```
